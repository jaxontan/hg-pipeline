## 〇、一句话范围

**1 个 `.blend` 文件 · 5 个空间组 · 2 个可切换灯态 · 8 个占位机位 · 0 帧渲染 · 0 个成片三维镜头。**

它不是美术资产，是**质量一致性核对工具**：用来回答「同一夜被三个视角讲三遍，光和机位会不会跳、会不会穿帮」。做完出两张表、签一次字、归档。

## 一、要做的东西（逐项，可直接照着建）

| 编号 | 对象 | 具体做法 | 验收标准 | 对应场景 |
|---|---|---|---|---|
| **B01** | `S00` 楼层总控平面 | 24×12m 占位楼板 + 走廊居中 2.4m + 6 个房间体量 + **走廊转角遮挡体**；每个房间打自定义属性 `circuit` | 三视角下 6 景相对位置不矛盾；连拍动线能从任一景走到任一景不被墙挡死 | 全片 |
| **B02** | 回路分区标记 | 两个集合 `CIRCUIT_EMERGENCY`（护士站 / 走廊 / 配电间）与 `CIRCUIT_NORMAL`（行政办 / 茶水间 / 药房），用**不同颜色的薄板**压在地面上 | 断电态下一眼能看出哪些房间还有电、哪些全黑；不靠记忆判断 | 断电 47 分钟 |
| **B03** | `S01` 走廊两态光位 | `LIGHT_NORMAL`：5 盏冷白顶灯 + 6 景各 1 盏；`LIGHT_BLACKOUT`：6 盏低位冷青应急灯 + 走廊尽头 + 护士站残光 + 台灯暖光 + 配电间残光 | 一键切换两态后，同一机位画面光比可读；不出现「全黑」或「全亮」；两态都不漏灯 | 冷开场 0–3′、全片 |
| **B04** | `S01` 三视角机位一致性 | 同一走廊给 4 个机位：冷开场全景 + A 线（沈砚）/ B 线（罗慧）/ C 线（姜培）回溯机位 | 三视角机位都**不拍到**本视角不该出现的光源、门洞或人物动线；不提前泄第三幕信息（110） | 第一／二幕 |
| **B05** | `S03` 茶水间留白戏 | 两杯茶（一凉一热用颜色区分）、椅背上的毛衣、文件夹、水槽、椅子；机位 `CAM_S22_pantry` | 第 22 场 0 句案情台词时，一个机位能同时读到**两杯茶 + 文件夹**，且不靠特写提示情绪 | 第 22 场 |
| **B06** | `S05` 配电间合流 | 配电柜体量 + 应急回路残光 + 6 人站位圈（用空心圆盘占位，不建人） | 人最多、灯最杂的第三幕，走位不穿帮、不被柜体挡住关键反应 | 第三幕唯一合流点 |
| **B07** | `S04` 行政办公室（**补入项**） | 台灯（可调角度占位）+ 碎纸机 + 办公桌动线；机位 `CAM_S37_admin` | 第 37 场台灯光落在纸上、碎纸机动线顺、不拍到可读单据字段 | 第 37 场、试光样片 |
| **B08** | 两态切换开关 | `set_state("NORMAL"/"BLACKOUT")` 互换两组灯的 `hide_render` / `hide_viewport`，并把当前态写入 `scene["light_state"]` | 一键切换、无漏灯；切完不需手动补灯 | 全片 |
| **B09** | 验收输出 | 脚本末尾打印：集合清单、两态灯数、`circuit` 分区表、8 个机位、视线遮挡自检结果 | 控制台输出可直接贴进《光态一致性核对表》 | 签字用 |

> **B07 是补入项，须说明**：v1.3 补记写的是 Q2 最小 4 项（S00 / S01 / S03 / S05）。但高质量规格 §七 的**试光样片硬闸门第 3 段就是第 37 场台灯戏**，没有 S04 就验不了。因此实际执行为 **5 个空间组**，不是 4 个——这是规格内部对齐后的修正，不是加活。

## 二、明确不做（做了就是白做 / 违规）

| 不做 | 原因 |
|---|---|
| 材质、贴图、UV、渲染图、动画 | Q2 只验光位与机位，渲染一帧都不需要（153：不把特效当默认方案） |
| 人物模型、手部动作、面部 | 用站位圈占位；人物表演靠实拍 |
| ICU 全景、断电全院反应、监护仪跳动数字 | 结果镜头 + 声音 + 对讲机人声替代，建模反而显便宜 |
| 任何成片背景 / CG 延展 | 会推翻「三维镜头数 = 0」与 §七 成本表，须整体重出 |
| **可读文字**：院名、标识、药名、剂量、单据字段、屏幕上的系统界面 | **高质量 = 画面更清晰 = 4K 下会被看清**，110 美术层逐景禁令；高清晰度下风险比 Q1 更高 |
| 与三视角无关的第 7、8 个房间 | 061：场景数与成本近线性，且挤占高可见项预算 |

## 三、命名与工程约定

- **物体名一律 ASCII**（`NS_counter`、`OUT_emergency_00`…），中文只出现在注释与文档里，避免 Windows / Blender 控制台编码问题。
- 中英对照：`S00` 楼层总控 / `S01` 走廊 / `S02` 护士站 / `S03` 茶水间 / `S04` 行政办公室 / `S05` 配电间 / `S06` 药房。
- 集合分组：`S00_Floorplan`、`S01_Corridor`、`S02…S06`、`CIRCUIT_EMERGENCY`、`CIRCUIT_NORMAL`、`LIGHT_NORMAL`、`LIGHT_BLACKOUT`、`CAM_PREVIS`、`PROPS_KEY`。
- 机位自定义属性：`scene_no` / `perspective` / `previs_note`（写明「占位机位，非成片镜头参数」）。
- **尺寸是占位**（24×12m 单层、墙高 3m）。拿到实测搭景场地后必须重排 S00，否则所有机位结论无效。

## 四、运行步骤

1. Blender **4.x**（脚本对 EEVEE 引擎标识做了 4.2 前后兼容回退）。
2. 后台执行：`blender -b -P 对账_blender_q2_previs_v1.py`
3. 输出：脚本同目录 `对账_Q2_previs_v01.blend`。
4. 打开后先跑 `set_state("NORMAL")` / `set_state("BLACKOUT")` 各看一遍，逐个切 8 个机位。
5. 把控制台的分区表 / 灯数 / 视线自检结果贴进两张表：
   - **《断电两态光位表》**（摄影签字）
   - **《分场次机位表 + 光态一致性核对表》**（导演 / 摄影 / 美术三方签字）
6. 三方签字后 **`.blend` 归档，不进剪辑、不进制作流程**；后续按 §七 试光样片硬闸门进入实拍验收。

> 本机未安装 Blender，脚本只做过 Python 语法校验（AST），**未在 Blender 内实际运行**。首次执行请看控制台有无报错；若 `scene.ray_cast` 在你的版本签名不同，脚本已做 try/except 回退，会跳过视线自检并明确打印提示，不影响其余部分。
