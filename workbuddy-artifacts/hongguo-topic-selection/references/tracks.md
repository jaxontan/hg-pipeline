# 赛道清单与红利判定

> 资源口径：2026-09。数值须以平台当期公告与后台数据复核。

## 一、赛道分级

频道（男频 / 女频 / 通用）→ 赛道 → 细分切口。同一选题只归一个主赛道，其余打标签。

## 二、男频常用十条赛道

都市逆袭、战神归来、赘婿豪门、战神萌宝、重生复仇、悬疑推理、年代情感、古装权谋、玄幻修真、都市异能。

## 三、女频常用十条赛道

总裁甜宠、婆媳家斗、萌宝亲情、重生年代、替嫁错嫁、大女主复仇、闪婚虐恋、闺蜜反目、萌宠治愈、职场逆袭。

## 四、生命周期四阶段与动作

| 阶段 | 信号 | 动作 |
|---|---|---|
| 萌芽期 | 上新少但稳定上榜 | 差异化切口优先 |
| 爆发期 | 上新密集且上榜面广 | 提速抢窗口 |
| 内卷期 | 上新极密但设定重合 | 控成本或人群细分 |
| 衰退期 | 上新仍多但热度下行 | 题材迁移不恋战 |

## 五、拥挤度四项指标

上新密度、差异度、上榜率、成本水位。**当同类剧只能靠改剧名活下来时，这个赛道已经很难做。**

## 六、跟风窗口与复制难度

- 结构复制难度越低，窗口越短；人设与场景简单 → 供给涌入极快 → 速度取胜。
- 需要特定场景、特效或 IP 授权 → 窗口更长 → 靠品质或资源壁垒取胜。

## 七、蓝海交叉矩阵

把「身份/职业」与「关系/处境」两组维度交叉穷举，逐格核查是否已有同类供给；空白格写一句话故事并做可行性与合规复筛。**蓝海不是没人做的题材，而是需求明确、供给稀少的交叉点。**

## 八、人群分层与设计要点

| 人群 | 偏好 | 设计重点 |
|---|---|---|
| 下沉市场女性 35—55 | 家庭关系、情感尊严 | 情绪节奏、结局公平感 |
| 下沉市场男性 30—50 | 逆袭、实力证明 | 爽点密度、结果可视化 |
| 都市白领女性 22—35 | 职场、关系 | 人设质感、台词密度 |
| 年轻男性 18—30 | 悬疑、异能 | 规则自洽、反转质量 |

## 九、观看链路诊断

曝光 → 点开 → 首屏 → 首集完播 → 前 3 集留存 → 前 10 集留存 → 跟播 → 回访。逐节点排查，优先修复转化率最低的节点。
