# 成本、保本与投产推演

> 资源口径：2026-09。数值须以当期平台口径与后台数据复核。

## 一、场景成本分级

| 级别 | 场景 | 策略 |
|---|---|---|
| 最低 | 住宅内景、办公内景 | 复用性最高 |
| 中等 | 街区外景、商铺内景 | — |
| 中高 | 医院、酒店宴会厅 | 结果交代或替代 |
| 最高 | 法庭机构、特殊置景 | 尽量替代 |

## 二、角色数量与成本

极简级 3—4 人；精简级 5—6 人；常规级 7—9 人；丰富级 10—12 人。次要角色考虑同一演员分饰，群演批量打包。

## 三、特效可控性

能用镜头语言不用特效，能用光不用建模；光效与转场成本最低，复杂三维成本最高；设定特效镜头数量上限。

## 四、周期倒排

从目标上线日倒排；剧本阶段不可过度压缩；后期预留三成缓冲；审校不可压缩。**周期算错，窗口期一过题材就不值钱。**

## 五、收益变量分组

规模（有效播放量）、留存（完播率/集均时长/追更率）、转化（点开率）、成本（制作+后期）、收益（单元收入）。
**选题能显著影响的是留存与转化，不能影响的是单元收入与大盘。**

## 六、保本播放量反推

保本播放量 = 总成本（制作 + 后期 + 素材）÷ 保守单元收入。**不知道保本线，就无法判断该不该加投。**

## 七、三情景推演

保守（低于同题材均值，决定能否承受）/ 中性（接近均值，常规决策依据）/ 乐观（接近高位，评估上行空间）。标注前三大敏感变量。

## 八、追投与止损判据（投放前约定，变更留档）

- 追投：留存与转化双达标。
- 止损：连续两期低于门槛 / 成本超上界 / 留存持续下滑。
- 投放能放大内容，不能拯救内容；留存未达标时投放效率极低。
