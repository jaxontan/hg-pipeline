## 〇、结论先行

**三个判断，逐条可执行：**

1. **上一版不是高智力，是"信息扣留"。** v1 工业包写着「观众到最后仍不知道那一行附注是谁删的」，短句本身没错，但它是**作弊**：把答案扣在编剧手里不叫悬疑，叫不公平。高智力的第一判据是**观众能解、角色不能解**——差的不是复杂度，是信息分配的方向。
2. **因此「不用 Blender」必须重开，但只在一个角色上重开。** 成片资产仍不用、省返工的 previs 仍不用；**新增一种用途：编剧室的逻辑证明器**。063「能用光的不用建模」管的是**成片镜头成本**，管不到**剧本的验真**。三维镜头数 ≠ 三维文件数，§七「三维镜头数上限 = 0」不被推翻。
3. **高智力不靠加反转，靠减线索。** v1 的三次翻案每次都引入新解释层（护人 → 钱去哪了 → 制度），是"新增事实"；升级版改成**同一组 5 个事实被重解三次**，之后零新增。观众在第 40 分钟就具备全部推导条件，角色到 E8 才知道——这个 40′→E8 的**戏剧反讽区间**，才是智性剧的引擎。

**新版一句话卖点（20 字内）**：断电 47 分钟，三本账记着同一笔钱，时间却写着系统停机的那一分钟。

## 一、什么叫「高智力」：六条可复核判据

| # | 判据 | 可验证方式 | 违反后的样子 |
|---|---|---|---|
| I1 | **公平契约**：揭晓前观众已拥有解出答案所需的全部事实 | 台账逐格核对，答案所需事实首次出现时间 < 揭晓时间 | 「其实还有一段没给你看」 |
| I2 | **同一事实重解**：每次翻案只重排已有事实的因果，不引入新线索 | 翻案表每格标注所用事实 ID，且 ID 集合 ⊆ 前 18′ 已给集合 | 反转堆料、越看越像换了个案子 |
| I3 | **唯一主疑点 + ≤3 条在线支线**（029 / 194） | 主疑点一句话，贯穿 8 集；支线开启即关闭一个 | 多线并烧，观众记不住 |
| I4 | **答案是一个选择，不是一个身份** | 「谁干的」在 E1 可解；真正的问题是「她为什么宁愿失去清白」 | 只剩猜凶手的智力测验 |
| I5 | **智性的代价**：主角越会推导，付出的代价越大，聪明不解围 | 每次推导成功都伴随一次不可逆损失 | 高智商 = 开挂 |
| I6 | **情感不降级**：智性不替代关系张力（025） | 仍保留 ≥2 场「不推进情节、只改变关系」的戏 | 精密但没人味 |

### 反欺骗条款（8 条，编剧自检逐条打勾）

1. 禁止视角人物的**主观隐瞒**（她知道却不告诉观众）制造悬念；只允许她不知道、或误判。
2. 禁止最后一幕出现承担答案的**新人物**；答案必须由第一幕已登场者承担。
3. 禁止把答案藏在**没给过镜头的空间**；所有关键空间须在前 18′ 出现。
4. 禁止用专业知识一次性碾压观众：财务、电力、医院流程术语须**转译为可视物件**（029 / 194 门槛评估）。
5. 禁止「其实是记错了 / 做梦 / 双重人格」类追溯性改写。
6. 禁止同一个事实在不同视角里**物理上不一致**（由 §六 灰模验真）。
7. 禁止反派靠耍狠赢；他赢的必须是**制度性的半局**（v1 §六 已立）。
8. 禁止把「观众没猜到」当作成功指标——本剧的成功指标是**观众先于角色猜到**。

> **与爽剧的分界**：爽剧防「被看穿」，智性剧防「看不穿」。这一条差异会连带改掉三条红果口径，见下节。

## 三、谜题重构：把「对不上」改成「不可能」

### 3.1 唯一主疑点

> **22:47 这个在系统停机期间不可能存在的时间戳，是谁写进三本账的？**

v1 的「对不上」是**账目差额**（可以被"再查一查"糊过去）；升级版改成**物理不可能**（只能被解释，不能被稀释）。差额仍为 4,700 元，但它退居为事实，不再是谜面。

### 3.2 五个固定事实（18′ 前全部给全，此后零新增）

| ID | 事实 | 首次出现 | 表面含义（误导） |
|---|---|---|---|
| **F1** | 断电 22:14–23:01，共 **47 分钟**；备用电源**未自动启动** | 冷开场 0–3′ | 事故 |
| **F2** | 用药账 / 采购账 / 审计底稿各有一笔 **4,700 元**，时间戳均为 **22:47**；三处格式与笔迹一致 | 第一幕 | 有人趁乱改账 |
| **F3** | 应急回路只覆盖 **护士站、走廊、配电间**；行政办公室 / 茶水间 / 药房在普通回路 | 冷开场一镜带过（不给强调） | 布景细节 |
| **F4** | 碎纸机插普通回路；集屑窗里**只有一条**纸屑，宽度恰好等于页末附注一行 | 冷开场一镜带过 | 布景细节 |
| **F5** | 护士站→配电间 90 秒；配电间→行政办公室 90 秒；**站在配电间门口看不见行政办公室的门**（走廊转角遮挡） | 第一幕一句流程台词 + 美术平面图 | 流程交代 |

**第一幕另给三句非强调台词**（答案必需，不得删、不得加提示）：许知微 22:45 被派去配电间取应急灯；沈砚 21:50 打印底稿、23:10 到楼；陆鸣的报修单在断电前被作废。

### 3.3 三次翻案 = 同一组事实的三次重解

| 次序 | 视角 | 得出的结论 | 只用 | 推翻了什么 | 新增线索 |
|---|---|---|---|---|---|
| 1 · A | 沈砚 | 罗慧趁断电替许知微补记 22:47 | F1 F2 | — | **0** |
| 2 · B | 罗慧 | 她确补记过，但是**纸质**、23:01 后补；系统里的 22:47 必来自**另一台还通电的设备** | F2 F3 F4 | 推翻「有人在断电的办公室里操作系统」 | **0** |
| 3 · C | 姜培 / 陆鸣 | 备用电源 22:47 做过一次**手动负载测试** → 配电间在停电期间有电、有可写终端 → 22:47 只能产生在配电间 | F1 F3 F5 | 推翻「停电期间全院无电」 | **0** |

> 第三次不是"又查出一条新证据"，而是把 F3（冷开场那盏应急灯）**重新读了一遍**。这是 I2 的落点，也是全剧智力密度最高的一分钟。

### 3.4 唯一解（观众 ~40′ 可推出，角色 E8 才知道）

1. F3 + 第三次重解 → 22:47 的写入点**只能是配电间**。
2. F5 的 90 秒 + 三句台词 → 22:45–22:47 在配电间的只有**许知微**；沈砚 23:10 才到楼，罗慧 23:01 后在茶水间，姜培在材料室有对讲机人声。
3. F2 三处一致 → 是**一人一次性补录**，不是三人分别改账。
4. 动机：陆鸣的报修单被作废，她把负载测试时间补写进三本账，让那张单子"看起来按流程走过"——**护人，不是贪钱**。

**题眼**：真相不是被藏起来的，是被**三次认领**挤没的。
- 罗慧认：「是我替小许补的用药账」；
- 姜培认：用一份「合规但取证不完整」的说明认下流程漏洞，换掉维保款那条线；
- 沈砚认：以为是自己没守住职业底线。

三个人各自为了保住不同的人，抢着认下一个不属于自己的错。v1 的主题「所有人都在改一个数字」由此升级为**「所有人都在替别人担责，于是没有人看见真正发生了什么」**——结构没换，智力层级换了一档。

## 四、信息台账（公平契约的可审计核心）

**规则**：每个「不知」必须标注依据类型，**G = 几何证明 / D = 台词声明 / T = 时间不可能**。标 G 的格子须由 §六 灰模签字后方可写进剧本；无依据的「不知」一律判为作弊。

| 幕点 | 沈砚 | 罗慧 | 姜培 | 许知微 | 观众 |
|---|---|---|---|---|---|
| 冷开场 0–3′ | 不在场 (T) | 知 F1 F3，不知 F2 (G：走廊转角) | 知 F1，不知 F2 (G) | 知 F1 F5 | **已见 F1 F3 F4 F5** |
| 18′ 幕点① | 知 F1 F2 F5，**误判罗慧** | 知 F2，**误判是自己补的** | 知 F2，**误判是流程疏漏** | 知全部，**不说** (D) | 具备 F1–F5 + 三句台词 |
| 30′ 中点 | 知 F3 F4，仍误判 | 坦白 → 观众站到她一边 | 备两个版本 | 仍在场，未开口 | 完成第 2 次重解 |
| **40′ 幕点②** | 完成第 3 次重解，**但盲点仍在**（她认定责任在罗慧） | 抢着认 | 抢着认 | 沉默 | ✅ **可解出唯一解** |
| 48′ 两难 | 亲手裁掉附注那一行 | 不知 (G：不同回路、不同房间) | 在场，不知她删的是哪一行 (D) | 不知 (T) | 知道她删掉的正是唯一能证明「许知微在护人」的程序 safeguard |
| 60′ / E8 | 仍不知自己删错了什么 | 仍不知 | 仍不知 | 仍不知 | 带着答案进入 E2 |

**戏剧反讽区间 = 40′ → E8**，横跨全季。观众不是「等着被告知」，而是「看着一群人真诚地搞错」——这比任何一次反转都更耐看，且几乎不增加制作成本。

## 五、主角两难与智性的代价（重写 v1 §四）

v1：她删掉自己写的附注 → 失去清白。
**升级版**：那行附注是她 21:50 打印底稿时写下的**例行审计备注**「本机时间与系统时间须以主机日志为准」。第三次重解之后观众才明白，正是这行最普通的职业习惯，会强制把 22:47 拿去和负载测试日志比对——**它是全剧唯一能说出真相的东西**。

她为让报告"对上了"而裁掉它（示范戏二的动作原样保留），于是：

- 报告干净落地，评审通过，所有人都被保住；
- 但许知微那次护人的补录被重新归类为「篡改记录」，**代价落在了最没能力承担的人身上**；
- 而她当场不知道。F4「集屑窗只有一条纸屑」向观众证明：全片只裁过这一次，没有第二份证据藏在别处（反欺骗第 3、6 条）。

**I5 落点**：她每一步都推对了，每一步都让她更接近一个更坏的结局。聪明没有解围，聪明是代价的放大器。

**季问题改写（v1「观众答不上来」作废）**：
> 当六个人都在替别人担责，那笔维修款究竟是谁在院外签的字？

观众带着两个已知（22:47 是许知微写的；沈砚删错了东西）进入 E2，而剧中人一个都不知道。**"我知道你们都在撒谎"的优越感，比"我不知道"高级得多**，且天然支撑 8 集。

## 六、Blender 决策重开（正面回答「不用 blender 吗」）

### 6.1 三种角色，三种结论

| 角色 | 用途 | 是否启用 | 是否违反 063 / §七 | 变化 |
|---|---|---|---|---|
| A · 成片资产 / LED wall / CG 背景 | 进剪辑 | **否** | 是 | **不变**（v1.1 结论成立） |
| B · 省返工 previs / 虚拟勘景 / 光位机位 | 不进剪辑 | **否** | 否，但性价比不成立 | **不变**（三张纸足够） |
| **C · 逻辑证明器（新增）** | **不进剪辑、不渲染、只在编剧室** | **是，条件启用** | **否** | **本次新增例外** |

### 6.2 为什么 063 管不到角色 C

063 的第一性判据是「能用光的不用建模」，约束对象是**成片里出现的三维镜头**及其成本。角色 C 产出的是**一个用于验真的灰模文件**：它一帧都不进剪辑，`三维镜头数 = 0` 保持不变。v1.1 把「三维文件」和「三维镜头」隐含地当成了一件事——在 v1 的故事里这个简并无害，因为那时要防的是"谁能看见谁"吗？不是，那时防的是**连拍动线与灯位**。

**「高智力」改变的是需要被证明的东西**：公平契约要求台账里每一个「不知」都成立。本剧的「不知」不是纸面声明，而是**几何断言**——F5 的视线遮挡、F3 的回路分区、47 分钟内 6 个房间 × 6 个人的可达性、以及三视角机位下观众会不会提前看到不该看的东西（110 美术层约束）。这类断言在 3 视角 × 47 分钟 × 6 空间的交叉下是组合量的，纸面机位表**无法逐格复核**；一个漏掉的视线，就会让整季的谜题在第 40 分钟穿帮。

> 判据一句话：**当「不知」需要几何担保时，建模就不是美术开支，是剧本的验真成本。**

### 6.3 最小启用规格（刻意做小）

| 项 | 规格 |
|---|---|
| 文件 | **1 个 `.blend`**，不拆 7 个场景、不做材质贴图、不渲染、不进流程 |
| 几何 | 6 个房间体量 + 走廊转角（遮挡体）+ 门洞开口 |
| 分区 | `CIRCUIT_EMERGENCY`（护士站/走廊/配电间）/ `CIRCUIT_NORMAL`（行政办/茶水间/药房）两态可切换 |
| 时间 | 47 分钟时间轨上标 22:14 / 22:45 / 22:47 / 23:01 / 23:10 五个节点的人物可达位置 |
| 射线 | 从 5 个关键站位发可见性射线，验证「配电间门口看不见行政办公室门」及三视角机位不泄底 |
| 产出 | **《可见性矩阵》+《47 分钟可达矩阵》两张表**，编剧 / 导演 / 摄影三方签字 → 灰模随即归档 |
| 人工 | 半天至 1 天，一次性；不新增长期资产维护 |

**触发条件**：谜题依赖几何断言（本版成立）→ 启用。
**退出条件**：若后续改为纯财务/心理谜题（不依赖空间视线），或法务换机构导致空间重排，**立即退回 v1.1「不用」**，两张表改由纸面声明担责。

### 6.4 与 v1.1 的关系

v1.1 对 **v1 故事** 的判断完全成立，不予翻案；本包是**需求变更后的新增例外**，不是纠错。文档按规范追加补记，v1 / v1.1 原文保留。

## 九、编剧交接增补硬约束（对 v1 §九 追加，不覆盖）

**新增 5 条，与 v1 原有 8 条并列生效：**

2. 三次翻案所用事实 ID 集合必须 ⊆ F1–F5；每次翻案标注 ID，供第三方复核。

- 若改回免费竖屏分账 → §二 全部口径反转，本作废。
