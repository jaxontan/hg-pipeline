## 〇、结论先行

### 根因诊断（先认这一条）

**我把自己写的假设当成了你的要求。** v1 工业包 A3 写的是「单夜、室内为主、6 人、无特效」——那是我为了单集试水自己选的低成本档，我随后把它固化成硬约束，并用「063 能用光的不用建模」「三维镜头数上限 = 0」「三张纸替代」连续否决了三次升档请求。**你从未要求省钱。** 高质量与「低预算档」不兼容，所以被推翻的不是某一句结论，是那个前提。

### 三个结论

1. **高质量 ≠ 用 Blender 做场景。** 153 工序卡把「把特效当默认方案」明列为走偏。对一部单夜、室内、写实向的戏，低预算三维 CG 恰恰是**最容易显便宜**的一项——塑料感、光比不对、材质穿帮。本片视觉核心是断电 47 分钟的**光**，第一笔钱该给试光与灯具，不该给建模。
2. **但「不用 Blender」不再是默认答案。** 成本天花板打开后，v1.1 里否决 previs 的第 3 条理由（「增量人工换不来等价返工节省」）**整体失效**——它的分母是我自己设的低预算档。于是：**不进成片的灰模预演由「否」翻为「是」，理由从「省返工」改写为「保证三视角光态与机位一致性」**。v1 那 7 项清单复活，但定位是质量工具，不是降本工具。
3. **§七 成本表、周期倒排、三维镜头上限、069 预警阈值基线全部须重出**；§五 季结构、§四 人物张力、三次翻案顺序**不动**（结构层与制作档位正交）。保本口径仍不给数字——075 分母依赖红果分账口径，平台采购/定制模式下不成立。

## 二、「高质量」的可验收定义（六维，不写空话）

| 维度 | 可验收指标 | 本片最吃紧处 | 验收责任人 |
|---|---|---|---|
| **1 · 摄影与光** | 断电前 / 断电中 / 恢复三态的色温、光比、光位连续；同一空间三视角下光态一致；无灯具穿帮 | 冷开场 0–3′ 与第 37 场台灯戏；两态之间不得靠后期硬压 | 摄影指导 |
| **2 · 美术与道具** | 实景材质、老化与生活痕迹；单据 / 器械 / 标示的质感真实但**不可读出真实信息** | 6 个高复用内景的「住过人」感；不能像样板间 | 美术指导 |
| **3 · 声音** | 断电瞬间的声场塌陷、应急灯电流声、对讲机人声的空间定位、静默段的底噪控制；成片响度与动态范围合规 | 长剧质感约一半在声音；本片用声音交代「全院反应」而非画面 | 录音 / 声音设计 |
| **4 · 表演与调度** | 留白戏的时长与停顿不被剪碎；长镜头调度不靠特写提示情绪 | 第 22 场茶水间（0 句案情台词）、第 37 场删附注 | 导演 |
| **5 · 后期与成片规格** | 调色一致性、剪辑节奏、字卡与字幕规范、交付分辨率 / 色域 / 响度符合平台当期技术规格 | 三视角重复空间不得出现调色跳变 | 后期 / 调色 / 制片 |

## 三、钱花在哪：每元可见度排序

| 层级 | 项目 | 判断 |
|---|---|---|
| **高可见** | 试光与灯具、摄影机与镜头组、录音与拟音、实景美术材质、调色、**多给拍摄天数** | 升档优先全给这里；本片第一笔钱给「断电两态试光」 |
| **中可见** | 移动设备与稳定器、群演调度、道具细节、多机位覆盖 | 视档位逐级补 |
| **低可见 / 反效果** | 低预算三维 CG、无法实拍的大场面、堆特效镜头、高分辨率下暴露的粗糙建模 | **高质量下最该避开**：显便宜，且挤占前两项预算 |

**「花了也看不见」清单（明确不投）**：ICU 全景、断电全院反应画面、监护仪跳动数字、成片 CG 背景、材质精修但一闪而过的道具。前三项按 v1 §七 用**结果镜头 + 声音 + 对讲机人声**替代——高质量下这个替代方案不是省钱妥协，而是**更克制、更高级的表达**，须由导演在样片阶段确认观感（153 要求「替代方案须评估观感」）。

## 四、三档质量方案（推荐 Q2）

> 量级只给相对档位（基准 / 明显上升 / 显著上升），**不给倍数、不给金额**——须由制片按当地报价与班底实报实销测算（沿用 v1 不编造数字的纪律）。

| 项 | **Q1 基准档**（= 原 v1，低成本试水） | **Q2 精品档 · 推荐** | **Q3 旗舰档** |
|---|---|---|---|
| 光 | 常规灯具 + 一次试光 | **断电两态专项试光 ≥2 轮**，定光位表与色温表 | 全场景可编程灯光 + 光态预演 |
| 摄影 | 单机为主 | 双机 / 定焦组，留白戏上长镜头 | 多机位 + 虚拟制片协同 |
| 美术 | 可复用搭景，基础质感 | **实景材质与老化处理，6 景逐景验收** | 全定制搭景 + 道具考据 |
| 声音 | 现场同期 + 基础后期 | **独立声音设计、拟音、声场样带** | 全景声 / 定制混录 |
| 拍摄周期 | 8–10 天 | **明显上升**（试光、留白戏、双机不可压） | 显著上升 |
| 三维镜头 | 0 | **0**（不变） | 0，除非启用虚拟制片 |
| **Blender** | 不用 | **启用：不进成片的 previs**（§五） | 启用 + 视需要评估 LED wall |
| 合规压力 | 常规 | **上升**（见 §六） | 显著上升 |

**推荐 Q2 的理由**：它把钱全部投在「每元可见度」最高的四项（光 / 摄影 / 声音 / 实景美术 + 时间），不引入任何成片三维镜头，因此**不触碰 063 的审美原则，也不制造 CG 显便宜风险**；同时足以达到头部网剧的完成度。Q3 只在你明确要虚拟制片或有多季空间基准复用需求时才有意义。

## 五、Blender 决策（重开后的最终口径）

| 用途 | 进成片 | Q1 | **Q2（推荐）** | Q3 | 判据 |
|---|---|---|---|---|---|
| **A · 成片 CG / LED wall / 虚拟制片** | 是 | 否 | **否（条件启用）** | 条件 | 触发条件不是「想要高质量」，而是**存在实拍无法满足的空间需求**。本片 6 个内景均可搭景实拍，**当前无一项触发** |
| **B · 灰模 previs / 光位机位一致性验证** | 否 | 否 | **是** | 是 | 成本天花板打开后，previs 的增量人工可接受；理由由「省返工」改为**保证质量一致性** |
| **C · 编剧室逻辑证明器** | 否 | — | **撤回** | — | 建立在误读的 H1 公平解谜前提上 |

**Q2 下的具体启用范围**（不是做满 7 项）：

- `S00` 楼层总控平面 → 三视角下 6 景相对位置与连戏基准；
- `S01` 走廊 → **断电两态光位 + 三视角机位一致性**（本片最难的技术点：同一夜被讲三遍，光不能跳）；
- `S03` 茶水间 → 第 22 场留白戏的机位与物件距离（拍错就成过场）；
- `S05` 配电间 → 第三幕唯一合流点，人最多、灯最杂。

产出两态光位表 + 分场次机位表 + 一张光态一致性核对表，**不渲染、不做材质、不进剪辑、验收后归档**。`对账_blender_blockout_v1.py` 由「归档备选」升级为 **Q2 的 previs 底座**（保留 4.x 兼容回退；仍未运行、未进流程，启用时由美术执行并按实测场地重排尺寸）。

**退出条件**：若档位回到 Q1，或改用纯纸面三方签字即可覆盖一致性 → 立即退回 v1.1「不用」。若启用用途 A → **整体重出成本表、周期、合规预检**，视同新项目定位，不属升档。

> **一句话回答「不用 blender 吗」**：高质量档位下**要用**，但用的是「不进成片」的那一档，而且理由从省钱改成了保证光态一致性；成片 CG 仍不用。
